# SmartTradeAI – Binomo Edition

A fresh Expo / React Native Android-first analysis companion.

## Features in this starter
- Dark dashboard with Analysis, Manual Signal, History and Settings tabs
- 1-minute / 5-minute timeframe selector
- User-entered closing prices
- Basic EMA 9 / EMA 21, RSI 14 and 5-candle momentum scoring
- UP / DOWN / WAIT result with visible reasoning
- Session-only signal history and practice label

## Important limitations
- This is not an official Binomo app and does not connect to a Binomo API.
- It does not fetch live prices or read Binomo charts automatically.
- Screenshot permission alone cannot recognize candles.
- MACD, Bollinger Bands, Stochastic and ATR are currently a manual checklist, not calculated indicators.
- Signals are educational and do not guarantee accuracy or profit.

## Run locally
1. Install Node.js and Expo tooling on a computer.
2. Run `npm install`
3. Run `npx expo start`
4. Scan the QR code with Expo Go, or build an Android APK using EAS Build.

This repository is a starter implementation, not a signed APK.
